# 🪔 Vesak AR Lantern Experience

An immersive **Augmented Reality (AR) experience** built with **Next.js, Three.js, and MindAR**, designed to celebrate Vesak with a glowing interactive lantern that appears when scanning a QR target.

## ✨ Features
- 📱 Web-based AR experience (no app install)
- 🧠 MindAR image tracking
- 🧩 Three.js 3D lantern rendering
- 🌈 Animated lighting & rotations
- ✨ Spark particle intro UI
- 🧘 Personalized Vesak blessings
- 📷 QR/image target activation
- 🔳 Fullscreen immersive mode
- 🎨 Glassmorphism UI design

## 🧱 Tech Stack
- Next.js (React + TypeScript)
- Three.js
- MindAR
- GLTFLoader

## 🚀 How It Works
1. Enter name + choose blessing
2. Start AR experience
3. Allow camera access
4. Scan Vesak QR/image target
5. Lantern appears in real-world space

## 📂 Project Structure
/public/models → VLSSL.glb  
/public/targets → vesak.mind  
/components → ARScene.tsx

## ⚠️ Requirements
- Camera access
- WebGL-enabled browser
- HTTPS for production

## 🌍 Deployment
Recommended: Vercel / Netlify / AWS Amplify
